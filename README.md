# Document-Intelligence-Agent-PDF-Layout-Analysis-QA-Pipeline
A document understanding pipeline that extracts text, detects layout regions, and analyzes charts/tables from PDF pages using PaddleOCR, LayoutReader, and a Groq-powered vision model -- all tied together by a LangChain agent that answers natural language questions about the document.  Demonstrated on a page from the SWI 2023 report.
